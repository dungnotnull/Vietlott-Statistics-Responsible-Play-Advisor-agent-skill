## Overview

An educational skill focused specifically on Vietlott's four game formats — **Mega 6/45, Power 6/55, Keno, Max 3D** — teaching the actual combinatorial mathematics behind each game's odds and expected value (in VND) using established probability theory, and explaining clearly why no statistical method can predict individual future draws. It does **not** generate 'winning number predictions' and instead promotes statistical literacy and responsible-play awareness appropriate to the Vietnamese context.

Every numeric claim is **computed from first principles** (not hand-typed), **validated by a 75-assertion pytest suite**, and **grounded in a 30-source applied research brain** that maps each peer-reviewed finding to the exact skill component applying it.

## Architecture

A modular Claude Skill with a **chain-of-thought skill-router** dispatching to five specialized **sub-advisors**, with **hooks** (pre/post-processing) and **tools** (JSON-schema inputs, executable Python handlers). ## Core Capabilities

- Explain the specific combinatorial structure and odds for each Vietlott format (Mega 6/45, Power 6/55, Keno, Max 3D)
- Calculate expected value and house edge (in VND) for each format given published prize structures
- Debunk common "phương pháp dự đoán" / "soi cầu" / "số hot-cold" myths using probability and behavioral-economics research
- Explain why historical draw-frequency analysis does not improve future-draw prediction for a fair lottery
- Explain budgeting and entertainment-spending framing consistent with responsible-gambling research
- Recognize and flag problem-gambling risk indicators, with culturally appropriate Vietnamese-context resource guidance
- Explicitly refuse to generate or endorse 'predicted winning numbers' framed as having real predictive power

## Key Methodologies & Frameworks

- **Combinatorial probability theory** (single-pool, bonus-ball, hypergeometric, fixed-odds)
- **Independence of random events / law of large numbers**
- **Expected value and house-edge calculation** in VND
- **Behavioral economics of gambling** (gambler's fallacy, availability heuristic, near-miss effect, rapid-draw fallacy)
- **Responsible Gambling guidelines** adapted to Vietnamese regulatory (Decree 30/2007/ND-CP) and cultural context

## Quick Start

```powershell
# Full end-to-end CI verification (validate -> regenerate -> ingest -> independence -> calculators -> tests)
python scripts/run_all.py        # expects: 12/12 steps passed
# or
make ci

# Individual steps
python scripts/validate_config.py     # config schema validation (no deps)
python scripts/config_loader.py        # config parse validation
python scripts/seed_games.py            # regenerate games.json from calculators
python scripts/ingest_results.py        # ingest draw data (synthetic fixture by default)
python scripts/independence_test.py      # real statistical independence tests on ingested data
python -m pytest tests/ -q             # 100 assertions, <1s

# Reproduce every numeric claim in the references
python scripts/combinatorics.py
python scripts/keno_calculator.py
python scripts/max3d_calculator.py
python scripts/expected_value.py
python scripts/wheeling_analyzer.py
python scripts/risk_screener.py
python scripts/independence_test.py mega_6_45   # demo independence analysis on ingested data
```

(On Windows, set `$env:PYTHONIOENCODING="utf-8"` for Vietnamese console output.)
